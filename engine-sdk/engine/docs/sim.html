Phase 4 – Simulation Systems

All simulation systems sit on top of ECS v2 and the core runtime. They expose data-first worlds (sim worlds) and ECS systems that keep simulation in sync with entities and rendering.

Physics integration

Definition CPU physics backend (e.g. PhysX-style world) wrapped by engine/sim/physics and driven by the PhysicsSystem ECS system.

Example 
import { registerPhysicsSystem } from "engine/ecs/systems/PhysicsSystem.js";

registerPhysicsSystem(world, {
  phase: "physics",
  updateKind: "tick",
});

Related PhysicsBody component, Collider component, world.physicsWorld.

GPU particles

Definition Compute-driven particle simulation world (ParticleSimWorld) with emitter presets, per-particle metadata, and screen-aligned billboard rendering.

Emitter Types

Each emitter preset defines visual and physical behavior. The emitter controls everything about its particles:

Type Shape Description
firesphereRising orange flames with negative gravity
smokesphereLarge grey billowing clouds
sparkspointFast bright dots that fall quickly
fountainsphereWater jets upward then falls
magicsphereFloaty purple orbs
snowpointGentle falling white flakes
explosionsphereBurst of fireballs

Shape Types (Fragment Shader)

The emitter's shape property determines how particles are rendered:

  • sphere – 3D shaded ball with diffuse lighting (fire, water, magic)
  • point – Tiny bright dot (sparks, stars, snow)
  • soft – Gaussian glow with no hard edges (smoke, fog)
  • spark – Star/cross shape (magic effects, flares)

GPU Buffer Layout

Per-particle data stored in GPU storage buffers:

  • positionBuffer – vec4 [x, y, z, age]
  • velocityBuffer – vec4 [vx, vy, vz, gravity]
  • metaBuffer – vec4 [r, g, b, packed_size_shape]
Example – Create Emitter 
import { createEmitter, stepEmitters } from "engine/sim/particles/ParticleEmitterSystem.js";

// Create a fire emitter at position [0, 1, 0]
const fireEmitter = createEmitter({
  type: "fire",           // Uses fire preset (shape, color, physics)
  position: [0, 1, 0],    // World position
  continuous: true,       // Runs forever
});

// Each frame, step emitters to spawn new particles
stepEmitters(emitters, particleWorld, deltaTime, {
  positions, velocities, maxParticles, currentCount, logger,
});
Example – Custom Emitter Override 
// Override preset properties
const customEmitter = createEmitter({
  type: "sparks",
  position: [5, 2, 0],
  color: [0, 1, 0],       // Override to green sparks
  pointSize: 2.0,         // Larger than preset
  emitRate: 200,          // Faster emission
});

Related ParticleSimWorld, createParticleBillboardRenderer, particles_billboard_vertex.js, particles_billboard_fragment.js.

World / terrain simulation

Definition World-level simulation (WorldSim) that tracks time-of-day, weather, and terrain heightfields (single or chunked tiles), integrated via WorldSystem.

Example 
import { registerWorldSystem } from "engine/ecs/systems/WorldSystem.js";

registerWorldSystem(world, {
  phase: "postPhysics",
  updateKind: "tick",
  dayLengthSeconds: 600,
  terrain: { type: "chunked_heightfield" },
});

Related world.worldSim, sampleTerrainHeight, world persistence helpers and inspectors.

Physics sandbox scene

Definition Helper in engine/scenes/PhysicsSandboxScene.js that wires up a simple physics test room: light, free camera, floor plane, and four walls, plus a PhysicsSystem instance with standard material settings.

Example 
import { ToolsPhysicsScenes } from "engine/ToolsImports.js";

const { configurePhysicsSandboxScene } = ToolsPhysicsScenes;

configurePhysicsSandboxScene(world, {
  roomSize: 50,
  baseGravity: [0, -9.81, 0],
  staticFriction: 0.5,
  dynamicFriction: 0.5,
  restitution: 0.5,
  lightIntensity: 1.5,
  lightHeight: 20,
  cameraFar: 200,
});

Related Physics integration, Phase 4 simulation tests.

Physics sandbox inspector

Definition Inspector preset in engine/tools/inspector/PhysicsSandboxInspector.js that provides spawn, render, lighting, and physics controls for sandbox scenes (used by the Phase 4 test).

Example 
import { attachPhysicsSandboxInspector } from "engine/ToolsImports.js";

attachPhysicsSandboxInspector({
  getWorld: () => world,
  logger,
  getSpawnState: () => ({
    pendingSpawnPosition,
    baseSpawnPosition,
    ghostOffset,
    pendingSpawnType,
  }),
  spawnObjectAtPosition,
  setPendingSpawnType: (modeId) => { pendingSpawnType = modeId; },
  getShaderState,
  setShaderState,
  getLightState,
  setLightState,
  getPhysicsState,
  setPhysicsState,
});

Related attachInspectorPanel, PhysicsSystem, Phase 4 UI.
