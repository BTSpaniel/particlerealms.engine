# Release Status

Particle Engine `0.8.0-alpha` is a source-available engine alpha.

## Included In First Alpha

- Engine source modules
- Engine runtime bundle
- Engine reference docs
- Curated SDK package
- WebGPU runtime foundations
- ECS, rendering, simulation, physics integration, particles, audio, and tooling APIs

## Deferred

- Editor public release
- Plauna public release
- Full platform SDK packaging
- Game-specific project releases

## Stability Labels

- **Stable:** expected to remain compatible during the alpha cycle.
- **Alpha:** usable but may change with migration notes.
- **Experimental:** available for evaluation, not compatibility-guaranteed.
- **Internal:** not part of the public SDK contract.
